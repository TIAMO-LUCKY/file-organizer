# file-organizer · 文件批量归档器

把一个乱糟糟的文件夹，按**文件类型**或**月份**自动归进子文件夹。

> 一个零依赖的小工具，纯 Python 标准库，双击就能用。

## 为什么做它

下载文件夹、素材文件夹堆到几百个文件时，手动分类是纯浪费时间。
这个工具把这件事变成一条命令。

**安全第一**：默认只「预览」，列出会怎么移动，**一个文件都不动**。
只有显式加上 `--go`，才会真正执行。

## 快速开始

不需要安装任何东西，有 Python 就能跑。

```bash
# 1. 预览（不会动任何文件）
python organize.py "D:/下载"

# 2. 确认没问题后，真正执行
python organize.py "D:/下载" --go
```

## 用法

```bash
python organize.py <文件夹>                  # 按类型归档（预览）
python organize.py <文件夹> --go             # 按类型归档（执行）
python organize.py <文件夹> --by date        # 按月份归档（预览）
python organize.py <文件夹> --by date --go   # 按月份归档（执行）
```

## 效果示例

整理前：

```
下载/
├── 报告.pdf
├── 风景.jpg
├── 会议录屏.mp4
├── 数据.csv
└── 素材.zip
```

跑 `python organize.py "下载" --go` 之后：

```
下载/
├── 文档/    报告.pdf  数据.csv
├── 图片/    风景.jpg
├── 视频/    会议录屏.mp4
└── 压缩包/  素材.zip
```

## 支持的类型

图片 / 视频 / 音频 / 文档 / 压缩包 / 代码 / 其他

想加自己的类型，改 `organize.py` 顶部的 `CATEGORIES` 字典即可。

## 安全说明

- ✅ 默认**只预览**，不加 `--go` 绝不动文件
- ✅ 只移动，**不删除、不覆盖**
- ✅ 跳过隐藏文件和子文件夹
- ✅ 纯标准库，**零第三方依赖**
